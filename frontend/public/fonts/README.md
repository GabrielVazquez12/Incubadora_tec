# Fuentes autoalojadas

Cormorant Garamond (normal e italic) y Montserrat (normal), pesos variables 400–700, subconjunto latino que incluye ñ, diéresis y acentos del español. Descargadas de Google Fonts; licencias SIL OFL completas incluidas en esta carpeta. Peso total de los tres WOFF2: 114856 bytes. Sin paquetes npm ni llamadas a Google al navegar por el portal. CSS usa `font-display: swap` y fallbacks del sistema.

Fuentes/licencias: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond y https://github.com/google/fonts/tree/main/ofl/montserrat.
